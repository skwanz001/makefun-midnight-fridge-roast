One line of text roasting a smart fridge that refuses to open after midnight, written to `/output/entry.txt` for make.fun's "Midnight Fridge Roast" bounty. The roast is a role reversal: the fridge is a strict parent and its owner is the grounded teenager — "I pay its electricity bill, and it still grounds me like a teenager."

## Run it

```sh
python3 main.py
```

Writes the roast to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
